# Achou Preço Bom

Versão didática do site de afiliados, organizada para permitir alterações pelo navegador.

## Comece por aqui

1. Abra este repositório no GitHub.
2. Pressione a tecla `.` para abrir o editor online `github.dev`.
3. Leia o arquivo [`GUIA-PARA-EDITAR.md`](./GUIA-PARA-EDITAR.md).

## Arquivos principais

- `src/dados/produtos.js`: produtos, preços e links de afiliados.
- `src/dados/categorias.js`: abas do menu.
- `src/App.jsx`: estrutura da página.
- `src/estilos/site.css`: cores e aparência.

## Executar

```bash
npm install
npm run dev
```

## Segurança

Nunca coloque senhas, Client Secret, Basic Token ou credenciais de API no código. Variáveis sensíveis devem ser configuradas apenas na hospedagem.
